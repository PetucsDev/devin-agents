# Ejemplo: refactor de backend

## Tarea

"Refactorizar el servicio `CardService` para reducir su complejidad ciclomatica."

## Respuesta esperada

1. Leer `src/main/java/.../CardService.java`.
2. Identificar metodos largos o con muchas ramas.
3. Extraer responsabilidades a clases mas pequenas.
4. Asegurar que los tests existentes siguen pasando.
5. Ejecutar `mvn clean verify`.
6. Responder con un resumen de los cambios y citas de archivo.
